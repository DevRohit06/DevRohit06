ROHIT(1)                    General Commands Manual                   ROHIT(1)

NAME
       rohit - software engineer who vibes with code

SYNOPSIS
       rohit [--build developer-tools] [--ship] [--ai-adjacent]
             [--location india] [--employer qbtrix]

DESCRIPTION
       Builds command-line tools, design systems and agent plumbing, then
       publishes them so other people can install them. Twelve packages
       across npm and PyPI, together doing about 5,700 installs a month.
       3,891 commits and 421 merged pull requests behind that.

       Spends the day on ripple, a generative UI runtime at qbtrix, where an
       agent emits a JSON widget tree and the runtime renders it as a live
       canvas. Spends a suspicious amount of the night on ocopus, a
       restaurant platform with 82 Prisma models and an MCP server exposing
       204 tools.

       Contributes to pocketpaw, a self-hosted AI agent — 294 merged pull
       requests, mostly in the security layer. Did not create it. That gets
       misreported and it is worth being precise about.

OPTIONS
       --build developer-tools
              The default mode. If a tool is annoying enough for long
              enough, it eventually gets rewritten as a CLI.

       --ship Preferred over --polish-indefinitely. Twelve published
              packages is the evidence for this claim.

       --ai-adjacent
              Not "AI engineer". Builds the boring parts agents need in
              order to touch real systems: CLIs, runtimes, MCP servers,
              validators.

FILES
       ~/projects/            everything shipped, with numbers
       /proc/now              what is running this week
       ~/blog                 rohitk06.in

BUGS
       Starts more projects than he finishes. Known. Won't fix.

SEE ALSO
       ls(1), connect(1), github.com/DevRohit06

DevRohit06                        August 2026                         ROHIT(1)
